# BP-005 — A silent ask is not work in progress

**Version:** 2 · **Updated:** 2026-10-02 · **Supersedes:** version 1, same day, which left a contradicted close open with no end.

**Does:** record the close that a reporter contradicted, and why a later silence is not the same event.

**Does not:** set the policy (that is charter D10 and the §4 still-broken sentence). It does not choose which current issue is open.

## Incident

On 2026-08-17 #165 was closed as fixed in v1.83.0, on our own checks. On 2026-08-31 the reporter said the MSSQL "server was not found" failure was still happening on that same stable build, and named further problems. The comment sat unread for a week because the queue did not re-read closed issues. The issue was reopened on 2026-09-07. Later fixes were asked to be retested on a nightly. The reporter has not accepted that later build. Closing again would repeat the premature close.

## Rule

The outcomes and the seven-day silence are charter D10. This page does not copy that table. Version 1 of this lesson, and BP-004, left dormant issues on the open list. Both are withdrawn. The issue database is updated in the same change as the close, or the next queue repeats the stale state.
